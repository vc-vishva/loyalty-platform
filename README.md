# To-Do List API

A simple RESTful API to manage your tasks efficiently.

## Features

- Create, read, update, and delete to-dos
- Filter to-dos by status or title
- Pagination and sorting support
- Optional date filtering (`startDate` and `endDate`)

## Tech Stack

- Node.js
- Express.js
- MongoDB + Mongoose
- Joi (for validation)
